# Security policy

Proof handles deployment artifacts and Shopify Theme Access credentials. Security reports should be private.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/BillyNoyes/Proof/security/advisories/new). Do not open a public issue for suspected credential exposure, artifact-validation bypasses, workflow-injection risks, or unauthorized theme access.

Include the affected commit or version, a minimal reproduction, expected and observed behavior, and potential impact. Do not include real Shopify credentials, GitHub tokens, customer data, or merchant data. Revoke any credential that might have been exposed before submitting the report.

## Supported versions

Proof is pre-release software. Security fixes are applied to the latest commit on `main` until the first stable release.
